# @pascal-app/cfs

Cold-formed steel (CFS) detailing extension for Pascal Editor.

This package adds CFS framing schemas, the `useCFS` editor-state store, framing/geometry/service-hole/panelization systems, and exporters (BOM, cut list, DXF, shop drawings) to the Pascal Editor scene graph. It does not modify upstream Pascal packages; UI surfaces live in `apps/editor/cfs/`.

See `docs/PROJECT_SPEC.md` for the architecture and build contract.
